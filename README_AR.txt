مساعدي الدراسي — نسخة تصوير الدروس وتلخيصها

محتويات الحزمة:
- index.html: واجهة عربية مناسبة للهاتف، لاختيار/تصوير صفحات الدرس، عرض الملخص وحفظه محلياً.
- server.js: خادم وسيط يرسل الصور إلى واجهة OpenAI Responses API ويعيد الملخص.
- package.json: متطلبات تشغيل الخادم.
- .env.example: أسماء إعدادات الخادم فقط.

مهم جداً:
هذه الحزمة ليست APK جاهزاً، وميزة التلخيص لا تعمل بمجرد فتح HTML. يلزم تشغيل الخادم على استضافة تدعم Node.js وضبط OPENAI_API_KEY في إعدادات أسرار الاستضافة (Environment Variables). لا تكتب المفتاح في index.html ولا ترسله لأي شخص. استخدام واجهة API قد يتطلب حساباً وإعداد فوترة وموافقة وليّ الأمر إذا لزم الأمر.

تشغيل الخادم على جهاز/استضافة Node.js:
1) ثبّت Node.js 20 أو أحدث.
2) نفّذ: npm install
3) أضف OPENAI_API_KEY في متغيرات البيئة الآمنة لدى الاستضافة.
4) نفّذ: npm start
5) افتح رابط الخادم من المتصفح. يجب أن تكون الواجهة والخادم على نفس النطاق.

بعد تشغيل الخادم:
- افتح الصفحة من رابط الاستضافة، ثم صوّر الدرس/اختر الصور.
- اختر حتى 8 صور واضحة، واضغط «أنشئ ملخص الدرس».
- احفظ النتيجة في «ملخصاتي». الحفظ محلي على نفس المتصفح/الهاتف.

تحويلها إلى APK:
لا تحوّل index.html وحده إلى APK وتتوقع أن تعمل ميزة التلخيص؛ الأفضل أولاً نشر الخادم ثم تغليف رابط التطبيق المنشور كتطبيق Android عبر أداة WebView موثوقة. احتفظ بنسخة احتياطية من الملخصات قبل تغيير التطبيق أو بيانات المتصفح.

الخصوصية:
الصور تُرسل إلى خادمك ثم إلى مزوّد الذكاء الاصطناعي لمعالجتها. لا ترفع صوراً فيها أسماء كاملة أو معلومات شخصية أو بيانات حساسة. لا تضع مفتاح API في التطبيق أو داخل ملف ZIP.
